##保卫大白饭开发程序

#背景
玩家扮演一个子智能体（subAgent），受命于用户（User）在用户睡觉时保护用户的token（大白饭）

#场景
用户的工作区（场景为一个办公室），有左门和右门，也有管道，许多房间有摄像头，5个ai原来应在办公区办公

#防御
主人在睡觉前为subagent留了一些预留token（相当于电量），subagent不可以动用除此之外的其他token
办公室左右门都有检测系统（耗token）和拦截系统（门）（打开系统耗token），当预留token耗尽时不能看监控和拦截系统和检测系统
检测系统：检测门口是否有ai
拦截系统：拦截门口的ai（拦截需至少开启3秒）

#5个ai简介
GPT：被监控盯着就不会移动，否则会移动，从右门进攻，在右门门口可被拦截系统拦截
Claude：从左门进攻，在左门门口可被拦截系统拦截
Qwen：从右门进攻，在右门门口可被拦截系统拦截
Doubao：移动速度极快，移动时会发出声响，从左门进攻
Deepseek：当场上出现deepseek的哼歌声时，要限时在监控中找到deepseek并为它带上铁盆，否则哼歌结束后deepseek将从管道进攻且不可拦截，速度比Claude快一点点

#胜负机制
胜：subagent在用户6点起床前守护住大白饭就胜利
负：在用户起床前白饭被吃就落败

#JumpScare
本游戏为全年龄向绿色健康游戏，因此不存在恐怖元素
jumpscare：对应ai跑进房间跳进大白饭盆当中将白饭一扫二光的画面，subagent尝试拦截但无果
失败动画：User从床上起来，发现自己token没了，对subagent生气
